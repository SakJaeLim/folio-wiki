## 해석할 때 필요한 범위

- 폴더 버전마다 새 WeKnora 지식베이스를 사용했습니다. 큰 폴더의 증분 생성 속도와 운영 중 장기 보관 비용은 측정하지 않았습니다.
- Lite 로그에서 일부 출처 참조 쿼리가 SQLite에 맞지 않아 `unrecognized token: "@"` 경고를 남겼습니다. 첫 위키 생성은 완료됐지만, WeKnora 페이지의 출처·삭제 추적까지 전부 검증됐다고 볼 수 없습니다. 앱에서 채택한 원문은 별도 SQLite 버전 기록으로 복원했습니다.
- 실험 문서는 합성 자료이고 담당자 이름은 시험 입력입니다. 여러 사용자 권한과 실제 조직에서 얻는 효과는 검증 대상입니다.
- 회귀 시험 5개를 통과했습니다. 잘못된 UTF-8 파일을 읽을 때 이전 상태 보존, 수정·삭제 뒤 재검토, 오래된 채택 요청 거절, 관련 없는 파일 수정, 보류 후 결정 재개, 두 폴더의 기록 격리를 확인했습니다. 예제 원문과 수정본의 SHA-256도 저장된 버전과 대조했습니다.
