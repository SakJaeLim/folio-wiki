# 수출국 다변화 기업의 예외는 어느 결정에 적용될까?

중소벤처기업부의 2026년 정책자금 융자계획에서 Ⅲ장 ①항은 우량기업에 대한 융자 제한을 다룬다. 2월 제141호와 4월 제281호에서 이 조항의 첫 문장은 같다. 달라진 것은 Ⅳ장 ‘2-2 수출기업글로벌화’의 우대사항이다. 제141호에서는 해외법인지원자금에 예외를 뒀고, 제281호에서는 수출국 다변화 기업까지 포함했다. 다른 사업인 ‘2-1 내수기업수출기업화’의 우대사항은 그대로였다. [2월 제141호](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1065960&cbIdx=310) · [4월 제281호](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1067487&cbIdx=310)

## 같은 공고로 확인한 여섯 결정

담당자가 Ⅲ장 ①항을 채택할 때 적용할 사업 절과 대상명을 기록했다. 각 사례는 독립된 작업 공간에서 실행했다. Folio는 당시의 원문을 기준으로 개정본에서 같은 조항을 직접 인용한 예외를 찾는다. 대상명을 지정하면 예외 문장에 열거된 이름을 대조한다. 기존 대상의 예외가 유지된 채 다른 이름만 추가된 경우, 기존 대상의 결정은 그대로 둔다.

| 채택한 기준과 검토 대상 | 예상 | 실제 |
|---|---|---|
| ①항, 수출기업글로벌화, 수출국 다변화 기업 | 재검토 | 재검토 |
| ①항, 내수기업수출기업화, 수출국 다변화 기업 | 유지 | 유지 |
| ①항, 수출기업글로벌화, 이미 예외였던 해외법인지원자금 | 유지 | 유지 |
| ①항, 수출기업글로벌화, 비슷한 이름 ‘수출국 다변화 예정 기업’ | 유지 | 유지 |
| ③항 세금 체납, 수출기업글로벌화, 수출국 다변화 기업 | 유지 | 유지 |
| 제281호를 채택한 뒤 제287호의 지원규모 정정을 반영 | 유지 | 유지 |

'수출국 다변화 예정 기업'은 비슷한 이름을 구별하는지 보려고 만든 시험용 명칭이다. 나머지 사례의 명칭과 변경 내용은 공고에서 가져왔다. ①항의 채택 문장은 HWPX에서 추출한 363번째 문단, 2-2의 예외는 793번째 문단이다. 화면의 행 번호는 같은 문단을 옮긴 Markdown 원문의 위치다. 이전 코드에서는 첫 사례도 그대로 채택 상태였다. [제287호 후속 정정](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1067495&cbIdx=310)

## 적용 방법과 범위

지침 검토에서 원문을 고르고 ‘다른 절의 예외를 확인할 범위’를 펼친다. 사업·절을 고르고 공고가 사용하는 대상명을 넣으면 그 범위의 결정을 기록한다. 두 칸을 비우면 같은 문서 전체에서 채택 조항을 직접 인용하는 예외를 검토한다. 기존 결정도 첫 동기화 때 당시 버전을 다시 확인한다.

이번 구현은 장 제목과 항 번호·이름을 함께 적은 한국어 인용, 또는 대상을 하나로 특정할 수 있는 문서 내부 Markdown 링크와 명시적인 예외·면제 표현을 지원한다. 절 이름만 비슷하거나 별도 문서에 예외가 실렸을 때, 대상이 간접적으로 표현됐을 때는 놓칠 수 있다. 재검토가 열리면 담당자가 현재 공고를 보고 적용 여부를 결정한다. 이 시험은 과거 두 개정의 문서 연결을 검증했으며 기업의 실제 자금 지원 자격을 판정하지 않았다.

## 다시 실행하기

저장소 루트에서 아래 명령을 실행한다. 공식 HWPX 세 건의 해시를 확인한 뒤 본문 문단 순서를 보존해 Markdown으로 옮긴다. 공고의 장·사업 번호를 제목으로 쓰고, 팀의 질문 한 장은 비교용 자료로 별도 생성한다. 결정의 근거는 공식 공고에서만 채택한다.

```sh
python experiments/exceptions/korean_sections.py --out cross-section-run
```

각 결정의 원문 인용, 출처 버전, 예상 상태와 실제 상태는 출력 폴더의 `results.json`에 남는다. [재현 스크립트](../../experiments/exceptions/korean_sections.py)
