# 기업마당 공고 한 건으로 확인한 첨부 연결

2026년 2차 예비창업패키지 예비창업자 모집 수정 공고의 URL 하나를 Folio에 넣었다. 앱이 받은 입력에는 파일명, 연도, 기준어가 없었다. [기업마당 공고](https://www.bizinfo.go.kr/sii/siia/selectSIIA200Detail.do?pblancId=PBLN_000000000119859)

| 앱에서 확인한 항목 | 결과 |
|---|---|
| 공식 파일 | 본문 1개와 별첨 5개 |
| 원문을 분석한 파일 | 공고 본문 PDF와 별첨 4 FAQ PDF |
| 목록에 표시한 나머지 파일 | 신청 매뉴얼, 사업계획서 양식, 증빙서류 제출목록 HWP, 주관기관 소개자료 |
| 연결 후보 | 본문 2쪽의 기계장치 기준과 FAQ 15쪽의 사무용 가구 집행 제한 1건 |
| 담당자가 확인한 뒤 | 같은 판본을 다시 가져왔을 때 확인 기록 유지 |

파일은 해당 공고 상세 페이지의 첨부 목록과 본문출력파일 영역에서 읽었다. 본문의 표 제목과 제한 문장에 공통으로 쓰인 ‘기구’가 두 원문을 연결했다. FAQ 답변은 사무용 가구에 적용되는 제한과 시제품 제작에 쓸 수 있는 비용을 함께 설명한다. 해당 쪽을 눌러 PDF를 직접 대조할 수 있다. PDF에 두 지면의 텍스트가 중복된 경우에는 연속된 인쇄 쪽 번호와 물리적 페이지가 일치할 때만 지면을 나눈다.

## 다른 공고의 파일을 섞은 시험

실제 기업마당 페이지에는 아래 두 파일이 없었다. 별도 시험에서만 그 페이지의 목록 사본에 두 파일을 끼워 넣었다. 둘 다 사무용 가구에 관한 같은 문장이 있다. 파일명을 ‘추가 FAQ’로 바꿔 연도나 사업명을 파일명만으로 판단할 수 없게 했다. 원본 파일은 공개된 판본의 SHA-256과 대조했다.

| 추가한 실제 자료 | 앱이 원문에서 읽은 단서 | 결과 |
|---|---|---|
| [2025년도 예비창업패키지 FAQ](https://ipsi.cku.ac.kr/bbs/cku_kr/1202/355859/artclView.do) | 표지의 ’25년 | 전년도 자료로 제외 |
| [2026년 사내벤처팀 FAQ](https://www.mss.go.kr/site/smba/ex/bbs/View.do?bcIdx=1066114&cbIdx=310) | 표지의 사내벤처팀 | 다른 세부 사업으로 제외 |

두 파일을 더해 목록이 6개에서 8개로 늘어도 연결 후보는 같은 1건이었다. 시험용 공간에서 미리 확인해 둔 기준도 다시 열리지 않았다. 이는 공고 한 건과 혼입 파일 두 개의 결과다. 다른 사업 전체의 탐지율은 아직 측정하지 않았다.

## 재현

저장소 최상위에서 실행한다. 네트워크 연결과 PATH에 등록된 `pdftotext`가 필요하다. 원문 판본이 바뀐 경우 실험은 기존 해시와 일치하지 않는다고 보고한다.

```sh
python -m experiments.exceptions.url_import
python -m unittest discover -s tests -p test_notice_url.py -v
```

실제 앱은 현재 공고의 공식 목록만 따라간다. 별도의 FAQ 게시판이나 관련 공고까지 검색하지 않는다. 이번 연결 방식은 한글 표 제목이나 표시가 있는 기준, 명시적인 제한 표현을 대상으로 한다. 설명이 이미지에만 있거나 두 문서가 동의어로 같은 개념을 설명하는 경우는 놓칠 수 있다. 업체가 제출한 자료와 비공개 폴더는 이 실험에 사용하지 않았다.
